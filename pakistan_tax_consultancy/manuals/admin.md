# Tax admin

You set the firm up, manage the team, verify payments and see every client.

## Setup

- **Website & Rules**: firm details, services and prices, FAQ, tax updates, testimonials (only with the client's consent).
- **Settings**: WhatsApp (click-to-chat now, Cloud API with approved templates later), email account, payment details and gateway, lead finder.
- **Team**: add staff, give each person their role, and switch **Ask VVS** on per person.
- **Roles & Permissions**: what each role may read and change.

## Bringing in the firm's data

**Import from Excel**: download the template, fill the **Clients** sheet and the **Returns** sheet (*Filed* for past years with the IRIS number and date, *In progress* for this year), preview, then import. A client already in the portal only gets its empty fields filled.

1. **Workspace → Import from Excel → Download the template** (`VVS_data_import_template.xlsx`). The **Filled example** next to it shows a finished file with 7 clients and 13 returns.
2. **Clients** sheet: one row per client; the name and client type are required. Add CNIC (individuals), NTN (AOP or company) and the mobile so each client can be recognised.
3. **Returns** sheet: one row per client per tax year, naming the client by CNIC, NTN, mobile or client code. *Filed* rows need the IRIS acknowledgment number and filing date; *In progress* rows only need the client and year.
4. Upload the file and press **Preview**: nothing is saved. Fix any rows marked *Error* in Excel and preview again.
5. Press **Import**. Re-importing the same file is safe; rows already in show *No change*.

The guide (PDF) and the video above walk through every step.

## Daily

- **Payments to Verify**: match the proof with the bank statement, then verify (creates the invoice and payment) or reject with a reason.
- **Consultations**: website bookings to call back.
- **Insights** and **Report Center**: workload, aging, filings, fees; export to Excel.

## Before going live

Remove the demo data, check the tax slabs of each year against the Finance Act, and give every person their own password.
