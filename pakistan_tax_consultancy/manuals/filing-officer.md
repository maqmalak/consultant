# Filing officer

You file approved returns on FBR IRIS and record the result.

1. **Filing Queue** lists approved returns. File the return on IRIS with the approved figures.
2. **Mark submitted on IRIS**: the portal checks that the figures are unchanged since approval and creates a filing record.
3. When IRIS gives the acknowledgment: **Awaiting Acknowledgment** → open the return → enter the **IRIS acknowledgment number** and attach the **FBR receipt** → **Record acknowledgment**. The client sees it at once.
4. If IRIS rejects the return: **Report filing error** with the error text. Fix it with the team, then **Retry filing**.

A return is never shown as filed without the acknowledgment number.
